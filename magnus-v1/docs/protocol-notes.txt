Variables Interchanged

	1- Go (bool) from js to py : Start calibration
	2- Difficulty level (int) from js to py : 4 levels, Then take prevImg using C2M
	3- Arm's Turn (bool) from js to py : Take curImg using C2M
	4- Resign (bool) from js to py : Stops the game using CEP

	5- Errors (int) from py to js : Error codes
		- Camera not found (12)
		- Couldn't calibrate (55)
		- Move Incorrect (100)
		- Move Incorrect on site (101)
	6- FEN Player's move (String) from py to js : Notation (prevLoc-curLoc), Find player's move using C2M
		& FEN Best move (string) from py to js : Notation (prevLoc-curLoc), using CEP
	7- Situation (int): Game Ending status if available:
		- 1: White won
		- 0: Black won
		- -1: Draw
